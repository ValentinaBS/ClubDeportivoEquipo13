# 🏢 Club Deportivo — Management System

Desktop management application developed in **C# and Windows Forms** as an academic project.

The application is designed for use by the **administrative staff of a sports club**, providing functionality to manage members, users, registrations and payment information.

## ✨ Features

* 👥 Member management
* 📝 Member registration
* 🔄 CRUD operations
* 🔐 User login and authentication
* 🗄️ SQL database integration
* 💰 Membership fee management
* ⚠️ Reports for overdue fees
* 👤 Administrative user management
* 🖥️ Desktop interface using Windows Forms

## 🏗️ Application Context

The application is designed around the administrative management of a sports club.

The main workflow includes:

```text
Administrative User
        │
        ▼
      Login
        │
        ▼
 Management System
        │
        ├── Members
        │
        ├── Registrations
        │
        ├── Fees
        │
        └── Reports
```

## 🗄️ Database

The application uses a SQL database to persist and manage the information handled by the system.

The database supports the application's CRUD operations and allows administrative information to be stored and retrieved.

## 🔐 Authentication

The system includes a login functionality for administrative users.

This provides a controlled entry point to the management system before accessing the application's administrative features.

## 📊 Reports

The application includes reports focused on membership fees, including the identification of **overdue payments**.

## 🚀 Getting Started

### Requirements

* Windows
* Visual Studio
* .NET SDK / compatible .NET environment
* SQL database

### Clone the repository

```bash
git clone https://github.com/DevJaSeb/ClubDeportivo-Proyecto.git
cd ClubDeportivo-Proyecto
```

Open the solution file in Visual Studio and configure the database connection according to the project's configuration.
